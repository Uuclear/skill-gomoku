# 技能特效与视觉元素增强 + UI 重叠修复 Spec

## Why

当前战斗场景只有两种特效（能量浮动文字、单色落点脉冲），且 `BattleController.BoardAffecting()` 把信息/经济类技能（id 11-15、18-23、25-30 等 17 个）全部排除在特效之外——这些技能释放时双方均无任何视觉反馈，对局缺乏表现力和可读性。同时战斗 UI 存在多处实测坐标重叠（toast × 表情栏、表情气泡 × 选目标条、HUD 昵称 × 能量数字、技能槽文字边界相切），影响可用性。

## What Changes

- **技能释放横幅**：任意技能生效时（无论己方/对方、是否有棋盘落点），在屏幕中上部显示一条横幅，包含技能名称 + 释放方标识，按技能类别着色，约 1.6s 后渐隐。
- **类别色彩语言**：落点脉冲（Pulse）颜色由"己方金/对方红"改为按技能类别着色——Info 蓝、Buff 绿、Debuff 红、Board 金、Special 紫（与 SkillBarView 槽位配色一致），双方可直观分辨技能性质。
- **无落点技能反馈**：信息/经济/增益/减益类技能不再静默——Buff 类在释放方玩家卡上播类别色光环，Debuff/信息干扰类在目标方玩家卡上播光环，替代之前完全无反馈的状态。
- **炸弹爆发特效**：技能 4（炸弹）落点播多层扩散环爆发 + 轻微震屏，突出高破坏性技能的打击感。
- **UI 重叠修复**：
  - 战斗 toast 上移，与表情按钮栏错开（当前 380..460 与 430..510 重叠）；
  - 己方表情气泡位置上移，避开选目标条区域（当前 -738..-662 与 -724..-668 重叠）；
  - HUD 玩家卡昵称区与能量区锚点去交叠（当前 0.62..0.65 交叠带），长昵称不再撞到能量数字；
  - 技能槽 cost 标签收缩到左上局部区域，不再满铺全槽与双行技能名边界相切。

## Impact

- Affected specs: 战斗表现（技能特效）、战斗 HUD 布局
- Affected code:
  - `client/Assets/Scripts/Battle/EffectPlayer.cs`（特效主载体：类别色脉冲、卡牌光环、爆发、震屏、横幅）
  - `client/Assets/Scripts/Battle/BattleController.cs`（特效触发点扩展、toast 位置、表情气泡位置）
  - `client/Assets/Scripts/Battle/HudView.cs`（昵称/能量锚点）
  - `client/Assets/Scripts/Battle/SkillBarView.cs`（cost 标签布局）
  - `client/Assets/Scripts/Battle/EmoteView.cs`（气泡位置参数，如由控制器传入则仅改控制器）
- 不涉及服务端、不涉及网络协议变更。

## ADDED Requirements

### Requirement: 技能释放横幅
The system SHALL 在任意技能生效事件到达时显示一条技能横幅，包含技能名称与释放方（己方/对方），横幅背景色按技能类别着色（Info 蓝 / Buff 绿 / Debuff 红 / Board 金 / Special 紫），约 1.6s 渐隐消失；横幅不得遮挡棋盘操作区与技能栏。

#### Scenario: 己方释放有落点技能
- **WHEN** 己方释放技能 16（单点封锁，Board 类）且服务端确认生效
- **THEN** 屏幕中上部出现金色横幅，显示"单点封锁"及己方标识，约 1.6s 后渐隐

#### Scenario: 对方释放无落点技能
- **WHEN** 对方释放技能 22（能量虹吸，Debuff 类）且收到服务端事件
- **THEN** 屏幕中上部出现红色横幅，显示"能量虹吸"及对方标识，约 1.6s 后渐隐

### Requirement: 类别色彩落点脉冲
The system SHALL 将棋盘落点脉冲颜色改为按技能类别着色（与技能槽配色一致），普通落子脉冲可保留原己/敌配色或采用中性色。

#### Scenario: 释放 Board 类技能
- **WHEN** 任意一方释放技能 4（炸弹）并在棋盘点播脉冲
- **THEN** 脉冲颜色为 Board 类金色系，而非单纯己金/敌红

### Requirement: 无落点技能的视觉反馈
The system SHALL 为没有棋盘落点的技能（信息、经济、增益、减益类）提供视觉反馈：Buff 类在释放方玩家卡播类别色扩散光环，Debuff/干扰类在受影响方玩家卡播类别色扩散光环。

#### Scenario: 己方释放能量涌动
- **WHEN** 己方释放技能 25（能量涌动，Buff 类）
- **THEN** 己方玩家卡上播放一次绿色扩散光环，不再完全静默

#### Scenario: 对方释放沉默
- **WHEN** 对方释放技能 18（沉默，Debuff 类）
- **THEN** 己方玩家卡上播放一次红色扩散光环

### Requirement: 炸弹爆发与震屏
The system SHALL 在技能 4（炸弹）生效时于落点播放多层扩散环爆发动画，并对棋盘区域施加一次短促轻微的震屏。

#### Scenario: 炸弹生效
- **WHEN** 任意一方释放炸弹且服务端确认
- **THEN** 落点出现至少两层递进的扩散环爆发，同时棋盘短促震动一次，随后恢复正常

### Requirement: 战斗 UI 元素不重叠
The system SHALL 保证战斗场景常驻/临时 UI 元素在 1080×1920 竖屏下互不重叠：toast 与表情按钮栏错开、己方表情气泡与选目标条错开、玩家卡昵称与能量数字不互相侵占、技能槽 cost 标签与技能名（含"剩X次"双行）不相切。

#### Scenario: toast 与表情栏同时可见
- **WHEN** 战斗中出现 toast 提示且表情按钮栏可见
- **THEN** 两者垂直区域无交叠，文字均可完整阅读

#### Scenario: 选目标时收到对方表情
- **WHEN** 己方处于选目标状态（选目标条显示中）且收到/发送表情
- **THEN** 表情气泡与选目标条垂直区域无交叠

#### Scenario: 长昵称玩家满能量
- **WHEN** 玩家昵称较长（如"黑方 · 一二三四五六"）且能量为 10
- **THEN** 昵称文本与"能量 10"文本无交叠，能量数字完整可读

#### Scenario: 技能槽双行显示
- **WHEN** 技能槽显示带"剩X次"的双行技能名且 cost 标签可见
- **THEN** cost 数字与技能名文本区域无交叠、不相切

## MODIFIED Requirements

无（本变更不修改既有功能需求语义，仅增强表现层与修正布局）。

## REMOVED Requirements

无。
